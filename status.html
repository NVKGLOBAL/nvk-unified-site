What is real

A capability registry for the whole NVK program. Every capability is classified by what the code and the live evidence actually show — not by what the plan hopes for. Statuses change only when evidence changes.

  • Operational — live and working
  • Partial — real, but incomplete
  • Simulated / Disconnected — looks like a feature, is not yet real or not connected
  • Missing / Blocked — does not exist yet, or is waiting on something outside the build
