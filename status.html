System Status

What is real

A capability registry for the whole NVK program. Every capability is classified by what the code and the live evidence actually show — not by what the plan hopes for. Statuses change only when evidence changes.

  • Operational — live and working
  • Partial — real, but incomplete
  • Simulated / Disconnected — looks like a feature, is not yet real or not connected
  • Missing / Blocked — does not exist yet, or is waiting on something outside the build

Keep operating. A redesigned storefront is staged and awaiting owner approval before anything live changes.

Canned string, no inference — verified at source. This is the live site’s failure to answer a simple question, confirmed in the code.

MLC / WebLLM models Simulated

Fake download loop (10→100% on a timer, then marked cached). CreateMLCEngine is imported but never called; no MLC weights are fetched.

Wire a real engine, or label the models “not yet wired” until one is.
Chain block production Partial — localnet only

Full Cosmos SDK app wired, verified in app.go. Localnet boot is a CI step, not a running network. No public testnet: no RPC, validators, or supply are verifiable.

Diagnose the failing Go CI job from its run logs, then bring up a public testnet.
Chain escrow Partial code / Missing exposure

Keeper is real on the testnet-hardening branch and moves funds correctly — verified by direct reads. But the module exposes no callable messages and no queries, and genesis has no escrow section. Escrow is unreachable.

Expose messages and queries, and add the escrow section to genesis.
Token unvk Missing

The denom in the chain code is udeltatheta, not unvk. The PRD’s unvk asset does not exist in the chain code.

Reconcile the proposed asset name with the chain code, per standing counsel: no public sale, 100% utility at launch.
Wallet / explorer Missing

No wallet or explorer code found in the chain repo.

Build after a public testnet exists.
ChatNVK multi-model chat Partial

Substantial code and server, README read in full. Runtime not verified here; gated on provider keys.

Provide provider keys and verify the runtime; it is the most complete chat core in the program.
Orb / visualizer systems Disconnected

Orb clusters exist in two repos, verified by file listing. They are not connected to any live surface, and their component code has not yet been read at component level.

Recovery in progress: deduplicate to one canonical copy, preserve the originals, and wire orb states to real activity (Listening / Thinking / Planning / Executing / Verifying / Complete / Blocked).
Seeker cards / TCG Missing as code

Build an implementation when prioritized; artwork is preserved as the design source.
Membership funnel / Stripe product Blocked

Create the Stripe product (owner action — needs the owner’s Stripe account), then wire the funnel to it.
NVK-shop Unread

Verify src/ before classifying.
