How the swarm is meant to run — the 3D Intelligence Operations Environment

From the Nov 23, 2026 proposal: the problem is not making agents intelligent, it is making them observable, manageable, coordinated and accountable. Six layers, one control plane:

Layer 1 — Global IntelligenceAll active projects, objectives and agent populations.
Layer 2 — Agent OrganizationsDepartments, teams, orchestrators and sub-agent hierarchies.
Layer 3 — Task GraphDAGs, dependencies, execution paths and coordination.
Layer 4 — Execution InfrastructureModels, tools, compute, budgets and resource utilization.
Layer 5 — Memory and KnowledgeShared knowledge, agent memory, RAG and project continuity.
Layer 6 — Verification and GovernanceEvidence, permissions, audit history and intervention.

Architecture: CODEXA Executive Orchestrator → Agent Runtime (Agent Registry, DAG Task Scheduler, Tool Execution, Resource and Budget Manager) → Event Bus → Telemetry and State Aggregator → Real-Time State Store → Evidence Ledger → Agent Relationship Graph → 3D Renderer → Audit and Verification → Operations Console → Authorized Control Commands. The registry, event bus and state aggregator are what make an agent inspectable instead of decorative. This page is the roster + brain step toward that; the live telemetry layer does not exist yet.
