NVK Intelligence / Codex

The technology program, stated honestly

The vision is locked and nothing is cut from it — but nothing is presented as live before it is. Below is what is real, what is simulated, and what is still being built.

Experimental

CODEXA — sovereign intelligence OS

A live shell is running at codexa.nvkglobal.workers.dev: onboarding works and the 122-module navigator loads. The shell is real. The intelligence inside it is only partly real — the rest is being built.

What is real

  • Small-model local inference via Transformers.js — 4 small models load and run on device.
  • Server-side Gemini call — a real cloud inference path exists in the server code.
  • The shell itself: onboarding, navigation, and the visual workspace render and work.

Simulated / in development — stated plainly

  • Aethel reasoner — currently canned responses. It is being built into real inference.
  • Model downloads and model selection — being wired to real engines. Downloads do not yet fetch real weights, and selecting a model does not yet change the engine.
  • Agent orchestration — services exist as code; the full spawn-run-report loop is not yet proven end to end.

The milestone that matters: one real model downloaded, loaded, and answering — in progress. When a small model is downloaded, loaded, and answers a question with real inference, that is the first milestone worth announcing. It has not been reached yet.

Experimental In development

Tri-Sophian Codex chain

Not publicly launched. Testnet hardening in progress.

Built on Cosmos SDK 0.47.6 and CometBFT 0.37.2. Chain-id: codex-chain-forge-1. The chain code is real and the application is fully wired — but there is no public testnet, no wallet, and no explorer yet.

About the token name: the denom in the chain code is udeltatheta. The asset name NVK / unvk from the PRD is proposed — it is not in the chain code. Until the two are reconciled, udeltatheta is what the code says and NVK / unvk is what is proposed.

Escrow: the escrow module exists as code, and its keeper is real on the testnet-hardening branch — but the module exposes no callable messages and no queries, and genesis has no escrow section. Escrow is unreachable from outside the binary. It is in development.

CI: continuous integration on the testnet-hardening branch is failing. The cause is unknown, pending the run logs — we do not guess at it. The front-end job passes; the Go job does not.

Proposed

Token facts, stated honestly

There is no public sale. Per standing counsel, the token is 100% utility at launch, with no public sale and no tradability timeline in writing. Supply and inflation are not decided. Nothing on this page is an offer, a sale, or a promise of a return.

What this page will never do: present any of this program as live, launched, or earning. There are no dashboards, metrics, or network statistics here — because there is no live network to measure. When something becomes real, it will be marked real, with evidence. Until then, it stays visible on the roadmap — it is not deleted, and it is not dressed up as finished.
